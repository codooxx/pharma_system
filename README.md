# Night Soft Pharmacy ERP

نظام مكتبي عربي لإدارة الصيدليات، مبني ببايثون ويعمل بدون إنترنت. صُمم ليكون بسيطاً للصيدلي وقابلاً لإعادة التسمية والتطوير والبيع.

## المزايا الحالية

- تسجيل دخول آمن وصلاحيات: مدير، مدير فرع، صيدلي، كاشير.
- نقطة بيع سريعة بالاسم أو الباركود.
- خصم المخزون آلياً حسب الأقرب انتهاءً (FEFO).
- الأصناف، وحدات البيع، التشغيلات، التكلفة وسعر البيع.
- تنبيهات المخزون المنخفض والأدوية القريبة من الانتهاء.
- مصروفات وتقارير مبيعات/تكلفة/ربح مع تصدير CSV.
- قاعدة SQLite محلية ونسخ احتياطي من داخل النظام.
- سجل تدقيق للعمليات المهمة وهيكل جاهز للتوسع.

## التشغيل على Windows

1. ثبّت Python 3.11 أو أحدث، وفعل خيار `Add Python to PATH`.
2. افتح PowerShell داخل مجلد المشروع.
3. نفّذ:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

الدخول الأول: `admin` / `admin123`. غيّر بيانات الدخول قبل الاستخدام الفعلي.

## البيانات والنسخ الاحتياطي

تُحفظ البيانات في `%USERPROFILE%\.nightsoft_pharmacy\pharmacy.db`. ويمكن إنشاء نسخة من شاشة «الإعدادات والنسخ».

## البناء كملف EXE

```powershell
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name NightSoftPharmacy main.py
```

## التخصيص وإعادة البيع

الهوية في `views/app.py`، البيانات في `models/`، ومنطق العمل في `services/`. الهيكل يسمح بإضافة الفروع، الحسابات، الضرائب، الوصفات، الربط السحابي أو PostgreSQL لاحقاً.

## نطاق الإصدار

هذه نسخة MVP عملية وليست بديلاً كاملاً لـ Odoo Enterprise. قبل البيع الفعلي يلزم اختبار قبول، سياسة نسخ احتياطي، إعداد الطابعة، ومتطلبات الضرائب والدواء في بلد العميل.
